# Korean-Language-Analyzer
이 프로젝트는 올바른 한글 맞춤법, 띄어쓰기, 발음을 도모한다.

## 1. 띄어쓰기 교정 모델

탐구질문 : 주변 음절의 특징을 기반으로 띄어쓰기를 예측하는 의사결정나무 모델은 어느정도의 정확도를 보이는가?

목표 모델 : 문장을 입력하면, 해당 문장의 띄어쓰기를 예측하는 모델

구현 계획 :
띄어쓰기 된 문장 데이터 수집
띄어쓰기를 제거하고 경계별 정답 레이블 생성
각 경계의 주변 음절을 특징으로 추출
scikit-learn의 DecisionTreeClassifier로 학습
예측된 경계에 공백을 삽입해 문장 복원
원래 문장과 비교하여 정확도 평가

구체적 계획:
데이터셋은 AIHub 인터페이스(자판/음성)별 고빈도 오류 교정 데이터 사용. (이하 데이터셋1)
데이터셋1의 cor_sentence를 정상 문장 데이터로 활용
띄어쓰기 제거 및 레이블 생성 코드를 직접 제작
의사결정나무 모델 구현

*주요 문제* : 데이터셋에서 띄어쓰기와 문장부호 오류 csv가 통합되어있으며 양이 일부에 불과함. > 라벨링 데이터에서 corr_sentence 스크랩 필요 // 또는 통합형 모델 제작으로 노선 변경
